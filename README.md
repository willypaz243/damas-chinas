# Damas Chinas

Juego de Damas Chinas implementado con React, TypeScript y Vite.

## Requisitos

- [Bun](https://bun.sh/) >= 1.0

## Instalación

```bash
bun install
```

## Desarrollo

```bash
bun run dev
```

## Build

```bash
bun run build
```

## Preview

```bash
bun run preview
```

## Linting

```bash
bun run lint
```
