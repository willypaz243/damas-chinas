# Damas Chinas

Juego de Damas Chinas implementado con React, TypeScript y Vite.

## Requisitos

- [Node.js](https://nodejs.org/) >= 18.x
- [pnpm](https://pnpm.io/) >= 8.0

## Instalación

```bash
pnpm install
```

## Desarrollo

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Preview

```bash
pnpm preview
```

## Linting

```bash
pnpm lint
```
